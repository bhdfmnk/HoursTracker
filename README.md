# Hours Tracker

Android-додаток для обліку робочих годин і заробітку (Kotlin + Jetpack Compose, minSdk 26).

## Що вміє

- Тиждень з понеділка по неділю, перемикання стрілками. Дотик на дати повертає до поточного тижня.
- На кожен день: початок, кінець, загальний час за день і гроші за день.
- Формат часу: 24 години (13:30) або AM/PM (1:30 PM), перемикається в Settings. Якщо кінець раніше за початок, зміна рахується через північ (07:30 -> 00:50 = 17h 20m).
- Погодинна ставка встановлюється один раз, зберігається на пристрої й застосовується до всіх днів.
- Ставка на вихідних: у суботу й неділю ставка множиться на коефіцієнт (за замовчуванням 1,5). Коефіцієнт змінюється в Settings, а для окремого дня його можна задати в деталях дня (наприклад ×2 для свята).
- Кнопка «Start shift / End shift» над таблицею: дотик записує поточний час, подвійний дотик або утримання відкриває ручне введення. Зміна, що почалася до півночі, завершується наступного дня на тій самій кнопці.
- Дотик на назву дня відкриває деталі: перерва (гг:хв), перемикач «відняти перерву від годин», нотатка.
- Підсумки тижня: загальні години, зарплата, кількість відпрацьованих днів.
- Податок у відсотках (необов'язково): показує податок і суму після податку. У Settings його можна повністю сховати.
- Вкладки Form / Preview / Share перемикаються свайпом вліво-вправо.
- Share: текстом, а також експорт у PDF, CSV і Excel (.xlsx), кожен з кнопками «Share» (надіслати) і «Save» (зберегти у вибрану теку).
- Settings: ставка, ставка на вихідних, податок, валюта (сітка з 10 символів + власний), формат часу, режим теми (системний / світлий / темний), мова (English / Українська). Показуються лише теми для поточного режиму: 2 світлі або 2 темні.

## Як отримати APK

### Варіант 1. Через GitHub (без Android Studio)

1. Завантажте вміст цієї теки в репозиторій (Add file -> Upload files). Файли з тими самими шляхами будуть замінені.
2. Вкладка **Actions** -> **Build APK** -> дочекайтеся зеленої позначки.
3. У завершеному запуску внизу, у розділі **Artifacts**, завантажте `HoursTracker-debug-apk`, розпакуйте й встановіть `app-debug.apk` (оновлення встановлюється поверх старої версії, дані зберігаються).

### Варіант 2. Android Studio

File -> Open -> оберіть цю теку -> Build -> Build APK(s). Командний рядок: `./gradlew assembleDebug`, файл з'явиться в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `Models.kt` - модель дня, розрахунок годин і грошей, форматування.
- `Strings.kt` - усі тексти двома мовами, назви днів, список валют.
- `Storage.kt`, `TrackerViewModel.kt` - збереження і стан.
- `Theme.kt` - палітри чотирьох тем (контраст не нижче 4,5:1) і `HoursTrackerTheme`.
- `Components.kt` - спільні елементи дизайну та діалоги.
- `QuickPunch.kt` - кнопка «Почати / Завершити зміну».
- `FormScreen.kt`, `DayDetailScreen.kt`, `PreviewScreen.kt`, `ShareScreen.kt`, `SettingsScreen.kt`, `MainActivity.kt` - екрани.
- `Exporter.kt` - PDF, CSV і xlsx без сторонніх бібліотек.
