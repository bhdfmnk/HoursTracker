# Hours Tracker

Android-додаток для обліку робочих годин і заробітку (Kotlin + Jetpack Compose, minSdk 26).

## Що вміє

- Тиждень з понеділка по неділю, перемикання стрілками ← →, дотик на дату повертає до поточного тижня.
- На кожен день: початок, кінець, загальний час за день і гроші за день.
- Час у форматі 24 години: `00:00` – `23:59` (наприклад `13:30`). Якщо кінець раніше за початок, зміна рахується через північ (07:30 → 00:50 = 17h 20m).
- Погодинна ставка один раз встановлюється, зберігається на пристрої й застосовується до всіх днів.
- Дотик на назву дня відкриває деталі: перерва (hh:mm), перемикач «відняти перерву від годин», нотатка.
- Підсумки тижня: загальні години, загальна зарплата, кількість відпрацьованих днів.
- Податок у відсотках (необов'язково): показує податок і суму після податку.
- Вкладки Form / Preview / Share: форма, звіт за тиждень, відправка звіту текстом (месенджер, пошта, нотатки) або копіювання.
- Світла й темна теми за налаштуванням телефону.

## Як отримати APK

### Варіант 1. Через GitHub (без Android Studio)

1. Створіть порожній репозиторій на github.com і завантажте в нього весь вміст цієї теки (разом із прихованою текою `.github`).
2. Відкрийте вкладку **Actions** → **Build APK** → дочекайтеся зеленої позначки (кілька хвилин).
3. У завершеному запуску внизу, у розділі **Artifacts**, завантажте `HoursTracker-debug-apk`, розпакуйте й встановіть `app-debug.apk` на телефон (дозвольте встановлення з невідомих джерел).

### Варіант 2. Android Studio

1. File → Open → оберіть цю теку.
2. Дочекайтеся синхронізації Gradle.
3. Build → Build Bundle(s) / APK(s) → Build APK(s), або просто запустіть на підключеному телефоні кнопкою Run.

Командний рядок: `./gradlew assembleDebug`, файл з'явиться в `app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `Models.kt` – модель дня, розрахунок годин і грошей, форматування.
- `Storage.kt` – збереження налаштувань і записів на пристрої.
- `TrackerViewModel.kt` – стан застосунку.
- `FormScreen.kt`, `DayDetailScreen.kt`, `PreviewScreen.kt`, `ShareScreen.kt`, `SettingsScreen.kt` – екрани.
- `Components.kt` – діалоги введення часу та значень.
